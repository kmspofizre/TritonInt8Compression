## План проекта: Triton kernels для INT4 квантизации (Llama-3.2-1B)

### 23.03.2026 - Исследовательский этап
**Задача:** Изучение Triton и материалов курса.

---

### 30.03.2026 - Базовые механизмы
**Иван: Обертка над кернелом**
*   **Зачем:** Обеспечение удобного интерфейса вызова Triton-функций из Python.
*   **DoD:** Python-класс (`Autotuner`/`Launcher`), запускающий пустой кернел на GPU.

**Женя: Квантизация в int4**
*   **Зачем:** Реализация алгоритма приведения fp16/bf16 к 4-битному диапазону.
*   **DoD:** Кернел, выполняющий операцию `round(x / scale + zero_point)` без упаковки.

**Кирилл: Matmul в bfloat16**
*   **Зачем:** Создание эталонного замера (baseline) для сравнения производительности.
*   **DoD:** Работающий кернел (X16 @ W16), выдающий результаты, идентичные `torch.matmul`.

---

### 06.04.2026 - Оптимизация и упаковка
**Иван: Валидация и бенчмаркинг**
*   **Зачем:** Автоматизация замеров скорости и проверка корректности вычислений.
*   **DoD:** Скрипт, выдающий TFLOPS и погрешность в сравнении с FP16 для разных размеров матриц.

**Женя: Упаковка int4 в int32**
*   **Зачем:** Сокращение объема занимаемой памяти весами в 4 раза.
*   **DoD:** Кернел упаковки (8 элементов int4 в один `int32`), подтвержденный тест уменьшения весов.

**Кирилл: Matmul с деквантизацией (X16 @ W4)**
*   **Зачем:** Выполнение инференса без полной распаковки весов в память.
*   **DoD:** Кернел matmul, принимающий `int32` (упакованные веса) и возвращающий `bf16/fp16` результат.

---

### 13.04.2026 - Интеграция
**Иван и Женя: Квантованный Linear Layer**
*   **Зачем:** Возможность вставки кастомных кернелов в стандартную архитектуру PyTorch.
*   **DoD:** Модуль `QuantLinear(nn.Module)`, заменяющий стандартный слой и работающий в составе модели.

**Кирилл: Эксперименты с Llama-3.2-1B**
*   **Зачем:** Проверка работоспособности системы на реальных весах и архитектуре.
*   **DoD:** Успешный Forward Pass модели Llama с замененными слоями без ошибок типизации и памяти.
